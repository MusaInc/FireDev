# Pulse

A small Android focus tracker used as the FireDev demo project. The home screen shows this week's
focus time and current streak; the logic lives in `app/src/main/java/dev/firedev/pulse/domain`.

- Tests: `./gradlew testDebugUnitTest`
- Build: `./gradlew assembleDebug`
- Preview deploy: `./scripts/deploy-preview.sh`
